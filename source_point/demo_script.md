# Internal Hackathon Demo Script — 26034

## Target duration

3–5 minutes.

## Opening — 20 seconds

Show a real packaged commodity.

Say:

> "An enforcement officer can currently spend significant time manually checking declarations on packaged products. We built an inspection assistant that reads the package, checks the applicable requirements, and produces evidence-backed findings."

## Demo

### Step 1
Open Scan.

### Step 2
Upload/photograph the real packet.

### Step 3
Show the live analysis states.

### Step 4
Show extracted declarations.

### Step 5
Show compliance verdict.

### Step 6
Click a violation.

The photograph should zoom/focus to the evidence region.

### Step 7
Show:

**What was found → What the rule requires → Why the system flagged it**

### Step 8
Generate the inspection report.

### Step 9
Open inspection history and show the saved inspection.

## Killer moment

Use a packet that contains an intentionally demonstrable issue.

The system should identify it with:
- exact field
- evidence region
- rule reference
- clear explanation

## Do not demo

- login
- settings
- empty dashboards
- fake analytics
- unfinished modules
- features that require an explanation longer than the demo itself
